# 📍 日本の思い出マップ SNS

日本地図上に「思い出の写真」をピン留めしてシェアできる、地図連携型 SNS アプリです。
友人と共同開発したポートフォリオ作品です。

![アプリ画面イメージ](./public/screenshot.png)

---

## 🌟 主な機能

| 機能 | 説明 |
|------|------|
| 📸 **投稿** | テキスト・住所・写真をセットで投稿 |
| 🗾 **地図表示** | 投稿した都道府県に写真がピンとして表示される |
| 🔍 **ズーム・パン** | 地図をピンチイン/ピンチアウト・ドラッグで操作 |
| ❤️ **いいね** | 投稿にいいね／いいね解除ができる（ブラウザをまたいで状態保持） |
| 💬 **コメント** | 投稿詳細モーダルからコメントを投稿・閲覧 |
| 🗑️ **削除** | 投稿をワンクリックで削除 |

---

## 🛠️ 技術スタック

### フロントエンド
- **React 19** — UIコンポーネント管理
- **Vite 7** — 高速な開発サーバー・ビルドツール
- **SVG カスタム地図** — 外部ライブラリ不使用で47都道府県を独自描画
- **react-zoom-pan-pinch** — 地図のインタラクティブ操作
- **localStorage** — いいね状態のクライアント側永続化

### バックエンド
- **Node.js + Express 5** — REST API サーバー
- **Multer** — 画像ファイルのアップロード処理
- **JSON ファイル** — 軽量データストレージ（DB不要で動作）

## 📁 ディレクトリ構成

```
location-SNS/
├── backend/           # Express APIサーバー
│   ├── index.js       # メインサーバー（ポート3001）
│   ├── routes.js      # ルーティング定義
│   ├── posts.json     # 投稿データ（永続化）
│   └── uploads/       # アップロード画像の保存先
│
└── final-map-app/     # Reactフロントエンド
    └── src/
        ├── App.jsx        # メインコンポーネント・状態管理
        ├── JapanMap.jsx   # SVG地図・ピン表示
        ├── PostForm.jsx   # 投稿フォーム
        ├── PostDetail.jsx # 投稿詳細モーダル・コメント
        └── App.css        # スタイル定義
```

## 🚀 ローカルでの起動方法

### 前提条件
- Node.js v18 以上

### 1. バックエンドを起動

```bash
cd backend
node index.js
# → http://localhost:3001 で起動
```

### 2. フロントエンドを起動

```bash
cd final-map-app
npm install   # 初回のみ
npm run dev
# → http://localhost:5173 をブラウザで開く
```

## 🔌 API エンドポイント

| メソッド | エンドポイント | 説明 |
|---------|--------------|------|
| `GET` | `/posts` | 投稿一覧取得 |
| `POST` | `/posts` | 新規投稿作成（画像付き multipart/form-data） |
| `DELETE` | `/posts/:id` | 投稿削除 |
| `POST` | `/posts/:id/like` | いいね追加 |
| `POST` | `/posts/:id/unlike` | いいね解除 |
| `POST` | `/posts/:id/comments` | コメント投稿 |

---

## 💡 工夫したポイント

- **SVG地図を自前実装**：Googleマップ等の外部APIに依存せず、47都道府県のSVGパスを独自定義。投稿のある都道府県は写真で塗りつぶされるビジュアルを実現。
- **住所から都道府県を自動判定**：テキストの住所から都道府県名を抽出し、地図上の対応する場所にピンを自動配置する仕組みを実装。
- **いいね状態の管理**：`localStorage` を使い、ページをリロードしても「押した/押していない」状態を保持。
